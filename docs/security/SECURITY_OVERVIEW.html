Original findings, ranked by severity

MediumSEC-001

New guest sessions can grow shared storage without an aggregate bound

Per-guest limits do not stop repeated fresh guests or resets. A real isolated-database probe retained all 12 workspace rows after eight admissions and four resets.

Remedy: serialize admission at a provisional limit of 256 retained workspaces; return a clear capacity response and preserve the current session if reset is rejected.

MediumSEC-002

An old uninstall receipt can erase a newer installation

A gap between account-wide uninstall and registry completion lets a new connection be overwritten as uninstalled, undercounting capacity.

Remedy: commit verified registry removal while account serialization is held; prove the newer callback survives old job completion.

MediumSEC-006

Invalid fake OAuth callbacks can permanently close CRM capacity

Twenty-five definitive fake denials create zero installations but reserve all 25 slots indefinitely. Real uncertain installations must still remain conservative.

Remedy: distinguish known no-install denials and count identified uncertain installations once; retain genuine unknown reservations.

MediumSEC-003

The public source route drops its intended sandbox header

The API supplies a source-file sandbox policy, but the bridge omits it. No script exploit was demonstrated; parser rejection, escaped text and canvas rendering remain in place.

Remedy: preserve the fixed sandbox and nosniff headers in the explicit response allowlist; test the actual route for PDF and text.

MediumSEC-005

The prepared live assistant buffers responses before checking size

Injected SDK responses proved complete 262 KB bodies were read before validation. Ordinary configuration remains fake-only; no live call was made.

Remedy: enforce decoded-byte and total response limits before SDK parsing; test oversized, compressed and delayed responses without network access.

LowSEC-004

Debug representations include protected settings

Synthetic probes showed the Settings representation includes database and server secrets. No public Settings response was found.

Remedy: exclude three sensitive fields from representations and verify with synthetic markers.
